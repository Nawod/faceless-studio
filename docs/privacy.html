Earth Has Bugs Studio — Privacy Policy

Last updated: 19 October 2026

Earth Has Bugs Studio ("the app") is a private tool used only by the owner of the YouTube channel @EarthHasBugs to upload and schedule that channel's own videos.

What the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos to the owner's channel, set their titles, descriptions, tags and publish times, and read basic channel information (channel name and statistics).

What is stored

An OAuth refresh token is stored locally on the owner's own computer so uploads can run on a schedule. No data is sent to any server operated by the app, no data is sold or shared, and no data about other YouTube users is collected.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service and Google Privacy Policy.
