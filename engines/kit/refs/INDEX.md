# Reference library: the channel owner's chosen look

Each file is a 6×2 sheet of 12 frames sampled evenly from a reference clip (read left→right, top→bottom).
**Read the 1–3 sheets that match the language you picked BEFORE you draw anything.** Match their *craft*:
shape language, palette discipline, how much is on screen, and how things move.
Never copy their characters, brands or text.

## The common craft (all 15)

- **One idea per shot, huge negative space, very few colours** (the background is 1 flat colour or a 2-stop gradient).
- Characters are **designed**, not assembled: a clear silhouette, a personality accessory, and an acting pose.
- **Motion never stops**, but it is economical: loops (dance, walk, bop) plus one *event* per beat.
- **Transitions are inside the picture:** the camera travels, an object transforms, the colour cuts on an action,
  an iris opens or a foreground object wipes past.
- No UI chrome, no boxes, no dashboard panels, no tiny labels.
